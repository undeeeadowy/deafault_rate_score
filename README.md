# Credit Risk — Анализ и предсказание дефолта по кредиту

## Описание

Проект по анализу кредитного риска на основе открытого датасета с Kaggle. Цель — построить модель, которая предсказывает вероятность дефолта заёмщика по характеристикам кредита и профилю клиента.

Подобные модели используются банками и финтех-компаниями для автоматической оценки кредитных заявок.

## Датасет

**Credit Risk Dataset** — [Kaggle](https://www.kaggle.com/datasets/laotse/credit-risk-dataset)

- 32 581 записей
- 12 признаков: возраст, доход, стаж работы, цель кредита, сумма, ставка и др.
- Целевая переменная: `loan_status` (0 — платит, 1 — дефолт)

## Что сделано

**Очистка данных:**
- Заполнение пропусков медианой в колонках `loan_int_rate` и `person_emp_length`
- Удаление строк с аномальным возрастом (>= 100 лет)

**Разведочный анализ (EDA):**
- Распределение возраста заёмщиков по статусу кредита
- Распределение процентной ставки по статусу кредита
- Доля дефолтов в разрезе цели кредита

**Ключевые находки:**
- Заёмщики с дефолтом получают кредиты под ставки 13–17%, тогда как исправные плательщики — под 10–12%
- Наибольший риск дефолта у кредитов на рефинансирование долгов (28.6%) и медицину (26.7%)
- Наименьший риск — венчурные кредиты (14.8%)

**Модель:**
- Логистическая регрессия
- Разбивка train/test: 80% / 20%
- One-hot encoding категориальных признаков

## Результаты модели

| Метрика | Значение |
|---|---|
| Accuracy | 85% |
| Precision (дефолт) | 0.78 |
| Recall (дефолт) | 0.43 |
| F1-score (дефолт) | 0.55 |

Модель хорошо распознаёт надёжных заёмщиков, но пропускает около половины реальных дефолтов. Это типичная проблема несбалансированных датасетов при использовании логистической регрессии без дополнительной настройки.

## Направления для улучшения

- Применить балансировку классов (`class_weight='balanced'`)
- Попробовать Random Forest или Gradient Boosting
- Нормализовать числовые признаки через StandardScaler
